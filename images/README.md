## How to Replace Placeholders

1. Download official product images from the sources above
2. Resize to reasonable dimensions (e.g., 800x800px or similar)
3. Save as `.jpg` or `.webp` with the exact filenames listed above
4. Replace the placeholder files in this directory
5. Commit and push

The site will automatically use these images via the `image_local` field in `affiliate.txt`.
